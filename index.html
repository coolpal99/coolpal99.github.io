Raspberry Pi Wi-Fi Network Scanner

An IoT device built on a Raspberry Pi that scans a Wi-Fi network and reports all connected devices with their details — built so a network admin can spot unwanted or unauthorized devices on the network.

How it works & what I learned
  • Device discovery: the Pi scans the local network and inventories everything connected to it.
  • Reporting: each device is listed with its details, making unknown devices easy to identify against what's expected.
  • Security value: unauthorized-device detection is a first line of defence for home and small-business networks.
  • Built during my final-semester co-op project at Fleming College.

HOME LAB · NOV 2026 · IN PROGRESS

Home Cybersecurity Lab

A hands-on lab on VirtualBox — Ubuntu as the target, Kali as the attacker, on an isolated network. Labs 1–5 done: built the lab, hardened Ubuntu with UFW and fail2ban, mapped it with Nmap, compared encrypted SSH with plain HTTP in Wireshark, and investigated login attempts in the Linux logs.

What I did & what I found
  • Hardened Ubuntu: updates, UFW default-deny with SSH allowed, fail2ban, SSH config reviewed.
  • Nmap: only port 22 open — OpenSSH 10.2 — confirmed against the target's own socket list.
  • Wireshark: SSH traffic unreadable, HTTP readable word for word; my own firewall blocked port 8000 until I opened it.
  • Log hunting: 4 failed SSH logins from Kali traced in auth.log and confirmed in journalctl — verdict: no intrusion, my own controlled test.
  • Labs 6–12 ahead, ending in a full SOC-shift capstone.
